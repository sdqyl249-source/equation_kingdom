# Equation Kingdom 🧮👑

## English
**Equation Kingdom** is an educational puzzle game built with Unity.  
The goal is to solve math-based cross puzzles by filling in the correct numbers to complete equations.  
Players progress through multiple levels with increasing difficulty, earning points and rewards along the way.  

### Features
- 🎯 Math puzzles (addition, subtraction, multiplication, division).  
- ⏱️ Countdown timer for each level.  
- 🏆 Score system with rewards.  
- 🔄 Multiple levels with progressive difficulty.  
- 📱 Exportable to Android, iOS, and WebGL.  

### How to Play
1. Start the game and choose a level.  
2. Fill in the blanks with the correct numbers.  
3. Submit your answer to check correctness.  
4. Earn points and unlock new levels.  

### Future Plans
- Integration with Unity Ads for monetization.  
- In-App Purchases (hints, extra time).  
- Enhanced UI/UX with animations and sound effects.

## العربية
**مملكة المعادلات** هي لعبة ألغاز تعليمية مبنية باستخدام Unity.  
الهدف هو حل ألغاز رياضية على شكل شبكة، وذلك بملء الأرقام الصحيحة لإكمال المعادلات.  
يتقدم اللاعب عبر مستويات متعددة تزداد صعوبة تدريجيًا، ويكسب النقاط والمكافآت أثناء اللعب.  

### المزايا
- 🎯 ألغاز رياضية (جمع، طرح، ضرب، قسمة).  
- ⏱️ مؤقت زمني لكل مرحلة.  
- 🏆 نظام نقاط ومكافآت.  
- 🔄 مستويات متعددة بصعوبة متزايدة.  
- 📱 إمكانية التصدير إلى أندرويد، iOS، و WebGL.  

### طريقة اللعب
1. ابدأ اللعبة واختر المستوى.  
2. املأ الفراغات بالأرقام الصحيحة.  
3. تحقق من الإجابة لمعرفة صحتها.  
4. اجمع النقاط وافتح مستويات جديدة.  

### خطط مستقبلية
- دمج إعلانات Unity لتحقيق الأرباح.  
- مشتريات داخل اللعبة (تلميحات، وقت إضافي).  
- تحسين واجهة المستخدم مع مؤثرات بصرية وصوتية.
